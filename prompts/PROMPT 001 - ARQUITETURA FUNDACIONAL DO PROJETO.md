# CONTEXTO DO PROJETO

Estamos construindo o MateMágico Champions.

Uma plataforma inteligente para treinamento de estudantes das Olimpíadas Brasileiras de Matemática.

O sistema deverá atender:

- OBMEP Mirim
- OBMEP Nível 1
- OBMEP Nível 2
- OBMEP Nível 3

O produto combinará:

- Banco de questões
- Treino adaptativo
- Simulados
- Campeonatos matemáticos
- Gamificação
- Ranking
- Gestão escolar
- Analytics pedagógico
- IA educacional (futuro)

---

# DIRETRIZES OBRIGATÓRIAS

Não criar um sistema monolítico.

O projeto deve ser preparado para:

- Crescimento por módulos
- Múltiplas escolas
- Múltiplos professores
- Múltiplos administradores
- Escalabilidade futura
- Integração com agentes de IA

Toda decisão arquitetural deve priorizar:

1. Simplicidade
2. Escalabilidade
3. Manutenibilidade
4. Documentação
5. Automação
